# Welcome to dotfiles!
## Install
  Installing these is easy, as long as you follow the steps.
1. Install niri, sddm, chromium, dunst, fuzzel, alacritty, micro, waybar, swaybg, and swaylock.
2. Run ''''bash -c "$(curl -fsSL https://raw.githubusercontent.com/keyitdev/sddm-astronaut-theme/master/setup.sh)"'''' to install the astronaut theme. Run a full installation with the astronaut one.
3. Download the config folder and move everything to the ''' .config ''' folder. Delete any duplicates.
4. Install the catppucin mocha chrome theme from the store.
5. run ctrl+e in micro and set the theme to catppucin-mocha. 
### You're now done! Restart and enjoy the theme.
